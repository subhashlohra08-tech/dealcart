DEPLOYMENT
1. Create KV namespace: DEALKART_PRODUCTS.
2. Put the Namespace ID in wrangler.jsonc.
3. Keep this exact structure:
   public/index.html
   src/index.js
   wrangler.jsonc
   README.txt
4. Deploy with Wrangler / Cloudflare Workers Builds.
5. Add secret ADMIN_PASSWORD in Cloudflare Worker settings.
6. Open the site and use the admin control to manage products.

IMPORTANT
- Never send your admin password, Amazon credentials, OTPs, or 2SV secrets in chat.
- Use affiliate links generated by the relevant marketplace's official affiliate tools.
- Marketplace prices and availability can change.
